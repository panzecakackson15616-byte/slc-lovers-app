# SLC-Lovers 数据同步 · 完整操作手册

> 跟着这份文档一步步操作，10 分钟内就能让两台手机数据互通。

---

## 📋 总览

整个流程分三大阶段：

```
阶段 A：在 GitHub 上准备（约 3 分钟）
   ↓
阶段 B：在你的手机上配置（约 2 分钟）
   ↓
阶段 C：在 TA 的手机上配置（约 2 分钟）
   ↓
完成 ✅ 两端数据自动同步
```

**前置条件**：
- 你和 TA 都已注册 GitHub 账号（免费）
- 两台手机都装好 SLC-Lovers APP
- 两台手机都已完成配对流程（输入了配对码）

---

## 阶段 A · 在 GitHub 上准备

### A1. 登录 GitHub
打开浏览器，访问 👉 **https://github.com**
（没有账号就先注册，免费）

### A2. 创建私有仓库

1. 点击右上角 **`+`** → **`New repository`**

2. 按以下填写：

| 字段 | 填什么 | 示例 |
|------|--------|------|
| **Owner** | 你的用户名 | `your-name` |
| **Repository name** | 仓库名（自己起） | `slc-lovers-data` |
| **Description** | 描述（可选） | `我们的私密空间` |
| **Visibility** | ⚠️ **必须选 Private** | 🔘 Private |

3. 其他选项**全部不勾**：
   - ❌ Add a README file
   - ❌ Add .gitignore
   - ❌ Choose a license

4. 点击 **`Create repository`** 按钮

5. 仓库创建成功，你会看到一个空仓库页面。**记住你的用户名和仓库名**，下一步要用。

### A3. 生成 Personal Access Token

1. 点击右上角你的头像 → **`Settings`**

2. 在左侧菜单**最下方**找到 **`Developer settings`** → 点击

3. 左侧选 **`Personal access tokens`** → **`Tokens (classic)`**

4. 点击 **`Generate new token`** → **`Generate new token (classic)`**

5. 按以下填写：

| 字段 | 填什么 |
|------|--------|
| **Note** | `SLC-Lovers`（备注名，随便写） |
| **Expiration** | 选 `No expiration`（永不过期）或 `1 year` |
| **Select scopes** | ✅ **只勾选 `repo`** 这一项（整个 repo 大项） |

   > 勾选 `repo` 后，下面所有子项会自动勾上，这是正常的。

6. 拉到最下面，点击 **`Generate token`** 按钮

7. ⚠️ **重要！** 页面会显示一串以 `ghp_` 开头的 Token，类似：
   ```
   ghp_AbCdEfGhIjKlMnOpQrStUvWxYz1234567890ab
   ```
   
   **立即复制保存**（可以用浏览器的复制按钮）！
   
   ⚠️⚠️⚠️ **这个 Token 只显示这一次**，关掉页面就再也看不到了。如果丢了只能重新生成。

## 阶段 B · 在你的手机上配置

### B1. 打开 APP，进入设置

1. 打开 SLC-Lovers APP
2. 底部 Tab 点 **`更多`**
3. 点 **`数据同步`**

### B2. 填写配置

在「GitHub 配置」区域，填入：

| 字段 | 填什么 |
|------|--------|
| **GitHub 用户名** | 你 A2 步用的用户名 |
| **仓库名** | 你 A2 步创建的仓库名（不带用户名前缀） |
| **Personal Access Token** | 你 A3 步复制的 `ghp_...` Token |

**举例**：
- 用户名：`your-name`
- 仓库名：`slc-lovers-data`
- Token：`ghp_xxxxxxxxxxxxxxxxxxxx`

### B3. 验证配置

1. 点 **`验证`** 按钮
2. 等待几秒，看到 **`✓ 仓库可访问`** 就说明配置正确
3. 如果显示 `✗ 仓库不存在或 Token 无效`，检查：
   - 用户名拼写是否正确
   - 仓库名是否正确（区分大小写）
   - Token 是否完整复制（不要漏字符）
   - 仓库是否真的是 Private（公开仓库也可以，但不推荐）

### B4. 保存配置

1. 点 **`保存`** 按钮
2. 看到 **`✓ 配置已保存`** 就成功了
3. APP 会自动立即拉取一次远程数据（首次会显示"无远程数据"，正常）

### B5. 确认同步已开启

页面上方的「同步状态」应该显示：
- 🟢 **已配置**
- 「自动同步」开关保持**打开**状态

## 阶段 C · 在 TA 的手机上配置

### C1. 确保已配对

TA 的手机必须先用**同一个配对码**完成配对（在配对流程中输入你创建的 6 位码）。

> ⚠️ 关键：两台手机必须用**同一个配对码**配对，因为加密密钥是从配对码派生的。配对码不同 → 密钥不同 → 无法互相解密数据。

### C2. 在 TA 的手机上重复阶段 B

完全一样的步骤：

1. 打开 APP → 更多 → 数据同步
2. 填写**完全相同**的：
   - GitHub 用户名（你的）
   - 仓库名（你的）
   - Token（同一个）
3. 验证 → 保存

### C3. 拉取你已上传的数据

1. 在 TA 的手机上，点 **`立即拉取`** 按钮
2. 几秒后，TA 的手机会同步到你在你手机上已有的所有数据
   - 聊天记录
   - 日记
   - 待办
   - 愿望清单
   - 留言板
   - 时光胶囊
   - 等等

配置完成后，**不用再做任何操作**，APP 会在后台自动同步：

| 触发时机 | 行为 |
|---------|------|
| APP 启动 | 自动拉取一次 |

## 🛠 常见问题

### Q1：换了手机怎么办？
在新手机上装 APP → 配对（用同一个配对码）→ 配置同步（用同一个 Token）→ 点"立即拉取"，所有数据就回来了。

### Q2：Token 丢了怎么办？
1. 去 GitHub 重新生成一个（重复 A3 步骤）
2. 旧 Token 会自动失效
3. 在两台手机上都更新 Token 配置

### Q3：想关闭同步怎么办？
设置 → 数据同步 → 关闭「自动同步」开关。
- 本地数据保留
- APP 仍可正常使用
- 想重新开启就再打开开关

### Q4：想彻底清空远程数据怎么办？
有两种方式：
- **方式 A**（推荐）：去 GitHub 删除整个仓库，然后重新创建一个空仓库
- **方式 B**：保留仓库，但 APP 端点"清空同步配置"，本地数据保留

### Q5：GitHub 仓库满了怎么办？
GitHub 私有仓库软上限 1GB，硬上限 5GB。情侣数据用 5 年也到不了 100MB，不用担仓。如果真满了，主要是照片占空间——目前照片不上传到 GitHub。

### Q6：同步会消耗很多流量吗？
不会。单次同步文字数据约 10-50KB。每小时自动同步一次约 0.1MB。一个月约 72MB，可以忽略。

### Q7：两人同时编辑会冲突吗？
当前策略：**条目数多的覆盖少的**。极端情况可能丢少量数据。生产级 merge（按时间戳逐条合并）在 TODO 列表里，可以后续加。

### Q8：GitHub 在国内访问慢怎么办？
- 大部分地区 GitHub API 访问正常
- 如果实在慢，可以考虑：
  - 方式 A：用 Gitee（码云）替代，API 兼容（需改 baseURL）
  - 方式 B：用 Cloudflare R2 / 阿里云 OSS 等对象存储
  - 方式 C：自建一个小服务器
- 告诉我你倾向哪个，我帮你改

## 🔒 安全说明

### 你的数据有多安全？

| 场景 | 是否安全 |
|------|---------|
| GitHub 仓库被黑客拖库 | ✅ 安全，数据加密，无法解密 |
| Token 泄露 | ⚠️ 攻击者可以读写密文，但解不开内容 |
| 配对码泄露 | ⚠️ 配合 Token 才能解密，单独无用 |
| Token + 配对码都泄露 | ❌ 不安全，需立即换 Token |
| 手机丢失 | ✅ 安全，Token 在加密存储里，不随备份泄露 |

### 谁能看到你的数据？
- **GitHub**：只能看到密文（加密后的乱码）
- **网络运营商**：HTTPS 加密，看不到内容
- **APP 开发者（我）**：没有任何后端，看不到任何数据
- **你和 TA**：唯一能解密的人（持有配对码）

## 📞 出问题了怎么办？

### 同步不工作的排查步骤

1. **检查网络**：两台手机都能上网吗？
2. **检查配置**：用户名/仓库名/Token 是否填对？
3. **点验证**：能否看到 "✓ 仓库可访问"？
4. **看错误信息**：同步页面会显示具体错误
5. **手动操作**：点"立即推送"再"立即拉取"试试
6. **看 GitHub 仓库**：访问你的仓库，看 `data/` 目录下有没有 `.enc` 文件

### 常见错误对照

| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `HTTP 401` | Token 无效或过期 | 重新生成 Token |
| `HTTP 404` | 仓库不存在或用户名错 | 检查用户名/仓库名 |
| `HTTP 403` | Token 权限不足 | 确认勾选了 `repo` 权限 |
| `HTTP 409` | 文件冲突 | APP 会自动重试，无需处理 |
| `Remote end closed` | 网络问题 | 检查网络，重试 |
