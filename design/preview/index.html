技术架构

🍎
iOS · SwiftUI
Swift 5.9 + Combine + JSON 本地存储 + iOS 17+
🤖
Android · Compose
Kotlin + Material 3 + Room + Coroutines + minSdk 26
💾
本地优先

Android

cd Android && ./gradlew assembleDebug
